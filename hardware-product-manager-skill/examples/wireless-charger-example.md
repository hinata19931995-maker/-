# Example: Bedside Wireless Charger

## Input

- Market: US / Europe
- User: Mass-market household users
- Scenario: Bedroom bedside table
- Charging: One device at a time
- Power: 15W+
- Price: $20
- Input: USB-C
- Indicator: LED + sound
- Night mode: LED should turn off automatically or manually

## Questions the Skill Should Challenge

- Is $20 a viable price band after fees and logistics?
- Does sound feedback conflict with the sleep-friendly scenario?
- Is 15W sustained charging thermally realistic in the proposed form factor?
- Which devices and standards must be supported?
- Is nighttime UX truly differentiated or merely table stakes?
- Is a power adapter included or excluded?
- What certification path applies by market?

## Expected Output

- Product definition
- Cost target
- Key assumptions
- Risk register
- Validation plan
- Product Gate
