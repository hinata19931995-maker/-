# Decision Framework

For high-impact decisions, use:

## Evidence
What do we know?

## Assumption
What are we assuming?

## Unknown
What remains uncertain?

## Risk
What happens if the assumption is wrong?

## Validation
How can we test it cheaply?

## Decision
What should we do now?

## Assumption Register

Classify assumptions:

- Confirmed
- Partially Validated
- Unvalidated

Prioritize:

High uncertainty × High impact

## Cost of Change Principle

Before each stage ask:

What could we learn now that would be expensive to discover later?

Prefer:

Research → Existing Data → User Interview → Competitive Analysis → Supplier Confirmation → Prototype → Engineering Test → Tooling → Production
