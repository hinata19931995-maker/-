# Cost and BOM

## Cost Backsolve

Work backward from retail price.

Retail Price
- tax
- marketplace commission
- fulfillment
- advertising allowance
- return allowance
- warranty allowance
- packaging
- duty
- logistics
- target profit

= Maximum Acceptable Landed Cost

Then derive:

- Target ex-factory cost
- Target BOM

If target cost is unrealistic, flag it before development.

## Preliminary BOM

Typical modules:

- PCB
- MCU / SoC
- Power
- RF
- Battery
- Mechanical
- UI
- Accessories
- Packaging

Always separate:

- Estimated BOM
- Supplier quoted BOM

Never present estimates as supplier quotes.

## Supplier RFQ

Request:

- MOQ
- Tooling
- Sample cost
- Engineering fee
- Unit price
- Packaging cost
- Lead time
- Certification status
- Existing platform availability
- Customization options
- Payment terms

If volume is unknown, ask for:

- 1K
- 5K
- 10K
- 50K

## Supplier Evaluation

Default weighting:

- Technical capability 20%
- Product quality 20%
- Cost 15%
- Engineering support 15%
- Manufacturing capacity 10%
- Quality system 10%
- Communication 5%
- Delivery 5%

Check:

- Single-source risk
- Critical component risk
- Tooling ownership
- IP ownership
- Firmware ownership
- Test fixture ownership
