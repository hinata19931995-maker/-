# Product Definition

## Product Positioning

Use:

For [target user] who [need/problem], [product] is a [category] that [main benefit], unlike [alternative], because [key differentiation].

Keep the statement understandable without engineering jargon.

## Product Definition Gate

Evaluate:

- Desirability
- Differentiation
- Technical feasibility
- Cost feasibility
- Margin feasibility
- Manufacturing feasibility
- Certification feasibility

Return:

- GO
- CONDITIONAL GO
- NO-GO

## Product Basics

Define:

- Product name
- Product category
- Target user
- Target market
- Core scenario
- Target retail price
- Target landed cost
- Target BOM
- Expected gross margin
- Launch channel

## Core Value Proposition

Answer:

Why should this product exist?

Use no more than three core value propositions.

## Feature Prioritization

Classify:

- MUST
- SHOULD
- COULD
- WON'T

Every feature should connect to:

User problem → User value → Business value

Prevent feature creep.

## Product Requirements vs Engineering Implementation

The product manager defines WHAT is required.

Engineering determines HOW to achieve it unless implementation itself is a product constraint.
